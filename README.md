# download-benchmark

Консольный скрипт на TypeScript. Делает 10 последовательных HTTP-запросов к указанному адресу, дожидается полного тела каждого ответа и печатает скорость скачивания. Между запросами пауза 1 секунда. Каждый успешный запрос пишется в лог сразу после завершения.

## Единицы

МиБ/с и КиБ/с (1 КиБ = 1024 байта).

## Требования

- Node.js 20 или новее
- npm

## Запуск

```bash
npm install
npm start --silent -- https://example.com/large-file.bin
```

Адрес обязателен и должен начинаться с `http://` или `https://`.

Пример вывода:

```text
1/10 ok 10485760 bytes 1.00s 10.00 MiB/s, 10240.00 KiB/s
10.00 MiB/s, 10240.00 KiB/s
```

Если ответ неуспешный, адрес недоступен или запрос длится дольше 60 секунд, скрипт останавливается и завершается с кодом 1.

## Проверка расчётов

```bash
npm test
```

Тесты формулы и паузы не ходят в интернет. Два других один раз скачивают картинку и главную страницу Google.
