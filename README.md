# download-benchmark

Консольный скрипт на TypeScript. Делает 10 последовательных HTTP-запросов к указанному адресу, дожидается полного тела каждого ответа и печатает скорость скачивания. Между запросами пауза 5 секунд.

## Единицы

МиБ/с

## Требования

- Node.js 20 или новее
- npm

## Запуск

```bash
npm install
npm start --silent -- https://example.com/large-file.bin
```

Адрес обязателен и должен начинаться с `http://` или `https://`.

Пример вывода:

```text
11.90 MiB/s
```

Если ответ неуспешный, адрес недоступен или запрос длится дольше 60 секунд, скрипт останавливается и завершается с кодом 1.

## Проверка расчётов

```bash
npm test
```

Тесты проверяют формулу скорости, подсчёт байт тела и паузу между запросами. Внешний сервер для них не нужен.
