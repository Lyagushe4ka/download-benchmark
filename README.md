# download-benchmark

Консольный скрипт на TypeScript. Делает 10 последовательных HTTP-запросов к указанному адресу, дожидается полного тела каждого ответа и печатает среднее время, общий объём и скорость скачивания.

## Единицы

| Величина | Единица | Как считается |
| --- | --- | --- |
| Время запроса | миллисекунды (ms) | от старта запроса до последнего байта тела |
| Среднее время | ms | сумма десяти времён / 10 |
| Объём | байты и МиБ | сумма размеров тел ответов. 1 МиБ = 1024 × 1024 байт |
| Скорость | МиБ/с (MiB/s) | общий объём / суммарное время десяти запросов |

В запрос уходит заголовок `Accept-Encoding: identity`, чтобы сервер отдал тело без сжатия и посчитанные байты совпали с переданными по сети.

## Требования

- Node.js 20 или новее
- npm

## Запуск

```bash
npm install
npm start --silent -- https://example.com/large-file.bin
```

Адрес обязателен и должен начинаться с `http://` или `https://`.

Пример вывода:

```text
url: https://example.com/large-file.bin
requests: 10 (sequential)
 1  812.4 ms  10.00 MiB
 ...
10  790.1 ms  10.00 MiB
average time: 840.1 ms
total downloaded: 100.00 MiB (104857600 bytes)
download speed: 11.90 MiB/s
```

Если ответ неуспешный, адрес недоступен или запрос длится дольше 60 секунд, скрипт останавливается и завершается с кодом 1. Среднее по незавершённой серии не печатается.

## Проверка расчётов

```bash
npm test
```

Тесты проверяют формулу скорости и подсчёт байт тела. Сеть для них не нужна.
